# Ide yang Berdampak

Materi kelas technopreneur untuk SMA Al Falah Boarding School Darmo, oleh Nazril Ravi Pratama.

## Jalankan di komputer
npm install
npm run dev

## Deploy ke Vercel
1. Push folder ini ke repository GitHub.
2. Di Vercel, pilih Add New Project, lalu import repository tersebut.
3. Framework otomatis terdeteksi sebagai Vite. Klik Deploy.

## Ubah isi
Hampir semua teks, link, dan data ada di src/data.js.
Foto ada di public/img.

## Pintasan saat presentasi
Panah kanan atau kiri: pindah bagian
F: layar penuh
